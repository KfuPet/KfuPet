## 🧑‍💻 开发

- 本项目采用 **C#** + **WPF** 开发（基于 .NET 8.0）
- Visual Studio 2022 版本要求：>= 17.8

### 🚀 快速开始

#### 方法一：直接双击解决方案文件（推荐）
1. 在项目文件夹中找到后缀为 **`.sln`** 的文件。
2. 直接双击该文件，系统会自动使用 **Visual Studio** 打开整个解决方案（包含所有子项目）。
3. 如果双击后没有反应，右键该文件，选择 **`打开方式` → `Microsoft Visual Studio`** 即可。

#### 方法二：从 Visual Studio 内部打开
启动 Visual Studio 后，可通过以下任一入口打开项目：

- **开始窗口**  
  点击右侧的 **`打开项目或解决方案`**，然后浏览并选择 `.sln` 或 `.csproj` 文件。

- **菜单栏**  
  依次点击 **`文件`** → **`打开`** → **`项目/解决方案`**（快捷键 `Ctrl + Shift + O`），同样选择 `.sln` 或 `.csproj` 文件。
